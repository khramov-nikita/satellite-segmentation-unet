# Обработка спутниковых снимков посредством нейронных сетей

Курсовой проект по дисциплине «Нейросетевые технологии анализа данных в сельском хозяйстве».

Семантическая сегментация земного покрова на синтетических RGB-патчах с помощью **U-Net** (TensorFlow/Keras).

## Возможности

- генерация синтетического land-cover датасета (5 классов);
- обучение U-Net с метриками Mean IoU и Dice;
- оценка на тестовой выборке;
- визуализация эталонных и предсказанных масок;
- консольное меню для запуска всего пайплайна.

### Классы

| ID | Класс |
|----|--------|
| 0 | прочее |
| 1 | посевы/поля |
| 2 | лес |
| 3 | вода |
| 4 | застройка |

### Пример метрик на test

| Метрика | Значение |
|---------|----------|
| Pixel Accuracy | ≈ 0.95 |
| Mean IoU | ≈ 0.90 |
| Mean Dice | ≈ 0.94 |

## Требования

- Python 3.10+
- зависимости из `requirements.txt` (NumPy, OpenCV, Matplotlib, TensorFlow, Pillow)

```bash
python -m pip install -r requirements.txt
```

## Быстрый старт

Рекомендуемый способ — консольное меню:

```bash
python src/console_app.py
```

Пункты меню:

1. Сгенерировать датасет  
2. Обучить U-Net  
3. Оценить на test  
4. Визуализировать результаты  
5. Полный пайплайн (1→2→3→4)  
0. Выход  

### Запуск скриптов по отдельности

```bash
python src/generate_dataset.py --train 140 --val 30 --test 30
python src/train.py --epochs 20 --batch-size 4 --lr 0.001
python src/evaluate.py
python src/visualize.py --n 3
```

Результаты сохраняются в `experiment/outputs/` (метрики, кривые обучения, визуализации, веса `.keras`).

```

├── README.md

├── Курсовой_проект.md          # текст курсовой работы
├── src/                        # исходный код
│   ├── console_app.py          # интерактивное меню
```
